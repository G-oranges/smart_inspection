🔧 根因分析

以下是导致此 Bug 的技术原因和建议的修复方案。

❌ 问题原因
  • Modal.confirm() 使用 Ant Design CSS-in-JS 内联样式渲染按钮
  • CSS-in-JS 的内联样式优先级高于 App.css 中的 [data-theme="dark"] .ant-btn-default
  • 虽然 App.css 中有 !important 覆盖，但 AntD v5+ 的 CSS-in-JS hash 作用域可能导致覆盖失效
  • Modal.confirm 默认挂载到 document.body，可能不在 ConfigProvider 的 CSS 作用域内
✅ 建议修复方案
  • 在 App.css 的 [data-theme="dark"] 块中，添加针对 .ant-modal-confirm-btns .ant-btn-default 的深色覆盖
  • 使用足够高的选择器权重和 !important 确保覆盖 CSS-in-JS
  • 或在 Modal.confirm 调用时传入 cancelButtonProps.style 根据当前主题动态设定
  • 全局方案推荐：通过 ConfigProvider 的 theme.components.Modal 统一配置
