# 手机号同步问题修复 - 进展文档

## 更新时间

2026-02-07 01:42

## 问题描述

修改个人信息中的手机号后，退出重新登录：

- ✅ 个人信息页面的手机号会更新
- ❌ 学生信息页面的手机号不会更新

## 根因分析

### 数据模型

系统中有两个独立的表存储手机号：

1. **`user` 表** - 用户账号的手机号 (`Phone` 字段)
2. **`student` 表** - 学生信息的手机号 (`Phone` 和 `Mobile` 字段)

两者通过 `Student.UserID -> User.ID` 关联。

### 问题根因

学生角色在个人信息页面修改手机号时：

- 前端调用 `PUT /api/students/me/contact`
- 后端只更新了 **Student 表** 的 `phone` 和 `mobile` 字段
- **没有同步更新 User 表**

导致：

- 个人信息页面从 Student 表读取 → 显示新值
- 登录时从 User 表读取 → 显示旧值
- User 表的 phone 从未被更新

## 解决方案 (方案 A)

修改 `UpdateMyContact` 方法，使用事务同时更新 Student 表和 User 表。

### 修改文件

`backend-go/internal/controller/extended_controller.go`

### 修改内容

```go
// UpdateMyContact 学生更新联系方式
// 同时更新 Student 表和 User 表，确保数据一致性
func (c *StudentController) UpdateMyContact(ctx *gin.Context) {
    // ... 权限检查 ...

    // 使用事务同时更新 Student 表和 User 表
    tx := c.db.Begin()

    // 1. 更新 Student 表
    if err := tx.Model(&model.Student{}).Where("userId = ?", userIdStr).Updates(...).Error; err != nil {
        tx.Rollback()
        // ...
    }

    // 2. 同步更新 User 表的 phone 字段（优先使用 phone，其次 mobile）
    userPhone := req.Phone
    if userPhone == "" {
        userPhone = req.Mobile
    }
    if userPhone != "" {
        if err := tx.Model(&model.User{}).Where("id = ?", userIdStr).Update("phone", userPhone).Error; err != nil {
            tx.Rollback()
            // ...
        }
    }

    tx.Commit()
    // ...
}
```

### 关键改进

1. ✅ 使用数据库事务确保原子性
2. ✅ 同时更新 Student 表和 User 表
3. ✅ 优先使用 `phone` 字段，其次使用 `mobile` 字段同步到 User 表
4. ✅ 任一更新失败时自动回滚
