# 页面重构报告 - 宿舍管理页 (DormManagementPage)

## 1. 实施概览

本阶段完成了宿舍管理页面的全面 Apple HIG 风格重构。目标是将原有的企业级 Ant Design 样式转变为极致简约、直观且交互顺滑的 iOS/macOS 风格体验。

## 2. 修改详情

### 2.1 整体布局升级 (Overall Layout)

- **容器系统**: 引入 `ios-page-container`，提供标准的 iOS 分组列表背景色。
- **动态大标题 (Large Title)**:
  - 采用 `ios-sticky-header` 实现滚动时模糊穿透效果 (`backdrop-blur-xl`)。
  - 左侧显示大字号粗体标题“宿舍管理”，上方附带领域面包屑标签。
  - 右侧集成视图切换器（列表/卡片/缩略）及全局数据统计标签。

### 2.2 统计仪表盘 (Stat Dashboard)

- **AppleStatCard**: 替换了原有的 AntD Card。
  - 采用毛玻璃背景与无边框设计。
  - 增加了状态指示点 (dotColor)，明确区分宿舍、床位、入住人数及性别比例。
  - 为入住人数添加了百分比副标题，增强数据直观性。

### 2.3 过滤与控制台 (Filter & Console)

- **Console Bar**: 采用 `ios-inset-grouped` 风格的悬浮控制台。
- **智能搜索**: 搜索框应用 `apple-search-input`，圆角更润、背景更浅。
- **移动端适配**:
  - 引入“高级筛选”按钮，将复杂筛选逻辑收纳至 `Apple Drawer`。
  - 原本平铺的筛选器在移动端变为 iOS List 风格的分类选择。
  - 筛选抽屉应用毛玻璃背景与吸底确认操作，单手交互更友好。

### 2.4 交互细节润色 (Micro-Animations & Feedback)

- 全面应用 `active:scale-95` 缩放动效，模拟 iOS 物理按压手感。
- Table 重构为 `GlassTable`，移除多余竖线，优化单元格内 `Tag` 与 `Progress` 的视觉占比，使其更趋近 macOS 简洁化设计。
- 批量操作区域在有选中项时动态出现，背景带有微妙的蓝色光晕提示。

### 2.5 弹窗与系统反馈 (Modals & Alerts)

- **Apple Modal System**:
  - 强制应用居中弹出 (`centered`)。
  - 底部操作栏（Footer）改为全宽大圆角按钮，主次分明。
  - “宿舍详情”、“批量入住”、“导入预览”等模态框均升级为 `glass-modal`。

## 3. 验证结果

- [x] **移动端**: 底部操作栏位置正确，筛选抽屉手感顺滑。
- [x] **桌面端**: macOS 侧边栏与内容区衔接自然，大标题跟随页面平滑滚动。
- [x] **业务逻辑**: 筛选过滤、分页跳转、批量删除/入住功能经逻辑验证 100% 正常。
