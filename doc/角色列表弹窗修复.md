# 角色列表弹窗修复

## 问题描述

左下角点击角色切换按钮后弹出的角色列表，在点击页面其他位置时：

- **操作栏（userMenu Dropdown）会消失**
- **但角色列表（rolePopover）仍然存在**

## 根本原因分析

代码采用了**嵌套的弹出层结构**：

1. **外层**：`Dropdown` 组件 —— 用户菜单（操作栏）
   - 由 `userMenuOpen` 状态控制
   - 使用 `onOpenChange={setUserMenuOpen}` 自动处理点击外部关闭

2. **内层**：`Popover` 组件 —— 角色列表
   - 由 `rolePopoverOpen` 状态控制
   - 嵌套在 `userMenuContent` 内部渲染

**问题机制**：

当外层 Dropdown 关闭时，Popover 默认挂载到 `document.body`，因此不会随着 Dropdown 的 DOM 销毁而消失。

## 修复方案

**方案 B**：通过 `getPopupContainer` 属性让 Popover 挂载到父容器内

### 修改文件

- `frontend/src/layouts/AppLayout.jsx`

### 代码修改

在角色切换 Popover 组件（约第 606-614 行）添加 `getPopupContainer` 属性：

```jsx
<Popover
  open={rolePopoverOpen}
  onOpenChange={setRolePopoverOpen}
  content={roleSwitchContent}
  placement="rightTop"
  offset={[12, -4]}
  overlayClassName="apple-popover-glass"
  trigger="click"
  getPopupContainer={(trigger) => trigger.parentElement}  // 新增
>
```

### 原理

- `getPopupContainer` 使 Popover 挂载到触发元素的父容器（即 Dropdown 的内容区域）
- 当 Dropdown 关闭并销毁其 DOM 时，Popover 的 DOM 也会一起被销毁
- 无需额外的状态同步逻辑

2. 点击左下角用户信息区域，打开操作菜单

4. 点击页面其他空白区域
5. **预期结果**：操作菜单和角色列表应同时关闭
