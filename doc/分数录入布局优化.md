## 1. 优化目标

参照 Stitch 中的「分数录入-侧边录入布局」设计稿，优化分数录入页面的桌面端布局。

## 2. Stitch 设计稿分析

设计稿采用 "Obsidian Command" 深色主题，关键布局特征包括：

| 特征 | 设计稿定义 |
|------|-----------|
| 整体布局 | 左侧导航栏 240px + 右侧内容区 |
| 内容区分割 | **4fr / 6fr** 双列布局（约 40%/60%） |
| 卡片风格 | 深色背景 (#161b22) + 细边框 (#30363d) + 12px 圆角 |
| 分数显示 | SVG 圆环仪表盘 + 蓝色光晕效果 |
| 成员列表 | 紧凑行布局 + 子容器背景色递进 |
| 扣分区域 | 标题 + 描述 + 分割线列表 + 底部添加按钮 |
| 提交按钮 | 全宽蓝色按钮 + 投影 |

### 3.3 关键改动

#### 布局比例（50/50 → 40/60）
```css
/* result-entry.css */
@media (min-width: 64rem) {
  .re-content-grid {
    grid-template-columns: 4fr 6fr;
  }
}
```

#### 深色卡片样式
```css
.re-dark-card {
  background: var(--co-glass-bg-heavy);
  border: 1px solid var(--co-glass-border);
  border-radius: var(--co-radius-md);
}
```

#### 分数光晕效果
```tsx
<div style={{
  background: `radial-gradient(circle at 50% 40%, ${scoreColor}40 0%, transparent 60%)`,
  filter: 'blur(40px)',
}} />
```

#### 工具栏融合
