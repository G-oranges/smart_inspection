# 界面设计与布局优化规范文档

本项目旨在通过 **Ant Design v6** 结合 **玻璃拟态 (Glassmorphism) 2.0** 风格，打造一套极具现代感、响应式友好且高性能的高级后台管理系统界面。本手册记录了优化的核心原则、实现方案及各页面的改进进展。

## 1. 核心设计原则

### 1.1 延续性：核心指标卡片

- **样式保留**：现有仪表盘的“多维指标卡片”（`stat-card`, `premium-glass`）保持原有视觉设计，包括其图标背景、数值布局及通透质感，不做结构性改动。
- **视觉增强**：仅针对背景模糊度、投影深度进行微调，使其在全屏幕尺寸下更自然。

### 1.2 视觉风格：玻璃拟态 2.0 (Premium Glass)

- **通透感**：使用 `backdrop-filter: blur(20px)`，背景配合半透明度（Light: 0.75, Dark: 0.85）。
- **层次感**：
  - 一级卡片：`var(--shadow-strong)`。
  - 二级组件：`var(--shadow-soft)`。
- **动感边框**：利用微弱的半透明边框（0.5px - 1px），增强元素边界清晰度。

### 1.3 夜间模式统一化 (Modular Dark Mode)

- **统一变量驱动**：所有组件必须通过 `antdTheme.js` 的 `Design Tokens` 或 `App.css` 的系统级 CSS 变量（如 `--color-surface`）获取颜色。严禁在 JSX 中硬编码颜色值。
- **语义化管理**：
  - `Surface`：基础底层背景。
  - `Elevated`：浮动层/弹出层背景。
  - `Glass`：玻璃感半透明层。
- **深度适配**：确保 AntD 的所有次级组件（如 Dropdown, Picker, Popover）在夜间模式下的 `backdrop-filter` 和 `box-shadow` 逻辑与主卡片保持一致。

### 1.4 响应式准则：无畸变布局

- **栅格系统**：严格遵循 `AntD Grid`，在 `xs/sm/md/lg` 断点处必须有明确的列数定义。
- **伸缩性**：禁止固定宽高，使用 `min-height`, `max-width` 配合 `flex-grow/shrink`。
- **移动端特化**：
  - 减小 `padding`（从 24px 缩减至 16px 或 12px）。
  - 列表项由“单行模式”转为“堆叠卡片模式”。
  - 图表开启 `ResponsiveContainer` 并设置最小触控高度（建议 300px）。
  - 信息密度自适应：在小屏下自动调整字体大小及间距，避免内容挤压失真。

### 1.5 交互体验：微交互

- **Hover 态**：卡片悬停时向上偏移 `4px` 并加深投影。
- **加载态**：统一使用半透明骨架屏或玻璃质感的 Loading 遮盖。
- **反馈**：操作触发后，按钮增加微弱的缩放（Scale 0.98 -> 1.0）反馈。

## 2. 全局 Design Tokens (Ant Design v6)

| Token 名称         | 描述         | 理想数值/配置                       |
| :----------------- | :----------- | :---------------------------------- |
| `borderRadius`     | 系统基础圆角 | 12px                                |
| `colorBgContainer` | 玻璃容器背景 | `rgba(255, 255, 255, 0.75)` (Light) |
| `boxShadow`        | 基础投影     | 更柔和、扩散范围更广的阴影          |
| `paddingLG`        | 页面大边距   | 24px (PC) / 16px (Mobile)           |
