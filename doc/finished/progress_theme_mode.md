# 项目进展文档 - 主题模式切换实现

## 📅 更新日期: 2026-01-26

## ✅ 已完成任务

- [x] **主题逻辑重构**: 在 `App.jsx` 中将单一主题状态重构为三态模式（跟随系统 `auto` / 浅色 `light` / 深色 `dark`）。
- [x] **系统偏好监听**: 实现了对 `prefers-color-scheme` 的实时监听，当模式设为“跟随系统”时，应用会随系统自动变换。
- [x] **组件开发**: 新建 `ThemeSwitcher.jsx` 通用组件，遵循 Apple HIG 设计规范，实现了响应式、带模糊效果的下拉菜单。
- [x] **布局集成**: 在桌面端 `macOS Layout` 和移动端 `iOS Layout` 中完美集成切换按钮。
- [x] **视觉优化**: 在 `index.css` 中添加了针对 `.apple-dropdown` 的玻璃拟态样式及激活态高亮逻辑。

## 🛠️ 技术细节

- **状态管理**: 使用 `themeMode` 记录用户选择，`activeTheme` 计算实际渲染值。
- **持久化**: 用户选择的模式会实时同步至 `localStorage`。
- **UI 组件**: 采用 Ant Design v6 的 `Dropdown` 为基座，结合 Tailwind CSS 强制覆盖样式以达到 Apple 质感。
