## 四、模块化操作规范

### 4.1 硬性约束 (MUST)

1. **禁止修改业务逻辑** - 仅做文件拆分，不改变功能行为
2. **禁止新增 eslint-disable** - 如有 lint 问题，需正确解决
3. **保持现有 Hooks 不变** - useTableState, useTableFetch, useBulkSelection 已接入的继续使用
4. **保持 URL 同步行为** - 筛选、分页、排序的 URL 同步不能破坏
5. **保持选择机制** - 批量选择、跨页选择逻辑不能破坏

### 4.2 拆分原则

1. **常量提取** → `xxxConstants.jsx` 或 `xxxFilterSchema.jsx`
   - 常量定义 (FILTER_KEYS, DEFAULT_COLUMNS, TABLE_KEY)
   - 归一化函数 (normalizeXxx)
   - 参数构建器 (buildXxxTableParams)

2. **列定义提取** → `XxxColumns.jsx`
   - 渲染函数 (renderXxxCell, XXX_RENDERERS)
   - 列配置生成 (createBaseColumns, createActionColumn)

3. **移动端卡片** → `XxxMobileCard.jsx`
   - renderXxxCard 函数转为 React 组件
   - 接收 props: item, index, { selected, onSelect }

4. **操作菜单** → `XxxActionSheet.jsx`
   - iOS 风格底部操作菜单
   - 使用 IOSActionSheet 组件

5. **操作逻辑** → `useXxxActions.jsx`
   - 所有 handle\* 函数
   - 导入/导出/删除等操作
   - 返回 { handleXxx, loading, ... }

6. **弹窗组件** → `modals/XxxFormModal.jsx`
   - 新增/编辑表单弹窗
   - 详情查看弹窗
   - 导入预览弹窗

### 4.3 组装层结构 (重构后的主页面)

重构后的主页面文件应只包含：

```javascript
// 1. 导入依赖
import { xxx } from './module-name';

// 2. 组件定义
function XxxManagementPage() {
  // 2.1 Hook 初始化
  const tableState = useTableState({ ... });
  const tableData = useTableFetch({ ... });
  const selection = useBulkSelection({ ... });
  const actions = useXxxActions({ ... });

  // 2.2 派生数据计算 (useMemo)
  const columns = useMemo(() => [...], [deps]);

  return (
    <PageLayout>
```

## 六、常见问题与解决方案

### 6.1 循环依赖

**问题**: A → B → A 形成循环

**解决**:

1. 将共用的常量/类型提取到独立文件
2. 使用统一的 index.js 导出

### 6.2 Hook 依赖穿透

**问题**: 子模块需要父组件的状态

**解决**:

1. 通过 props 传递
2. 使用 Context（不推荐，增加复杂度）
3. 将状态逻辑封装在 Hook 中，整体传递

### 6.3 JSX 提取为组件

**问题**: 原始的 render 函数依赖大量局部变量

**解决**:

```javascript
// 原始
function renderFoo() {
  return (
    <div>
      {localVar1} {localVar2}
    </div>
  );
}

// 提取后
function FooComponent({ var1, var2 }) {
  return (
    <div>
      {var1} {var2}
    </div>
  );
}
// 使用
<FooComponent var1={localVar1} var2={localVar2} />;
```

### 6.4 文件扩展名

**规则**:

- 包含 JSX 语法的文件使用 `.jsx` 扩展名
- 纯 JavaScript 逻辑使用 `.js` 扩展名
