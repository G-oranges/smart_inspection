# 个人中心与系统设置 UI/UX 设计规范 (Apple-like 玻璃拟态风格)

## 1. 设计目标与核心理念

- **目标**: 为查寝系统设计一套符合 Apple Human Interface Guidelines (HIG) 的个人中心入口及信息管理界面。
- **核心风格**: 延续系统的 **暗色模式优先** 与 **玻璃拟态 (Glassmorphism)** 视觉语言。
- **用户体验**: 强调轻量级操作（即触即达）与深度信息管理（抽屉式承载）相结合。

---

## 2. 设计 Token 清单 (对齐系统现有变量)

### A. 色彩 (Colors)

| Token                  | 值                       | 用途                                       |
| :--------------------- | :----------------------- | :----------------------------------------- |
| `accent`               | `#007AFF`                | 苹果蓝，用于主按钮、进度条、选中态         |
| `accent-soft`          | `rgba(0,122,255,0.10)`   | 浅蓝色背景，用于 Hover 或轻量高亮          |
| `accent-ring`          | `rgba(0,122,255,0.20)`   | 聚焦环样式                                 |
| `surface-dark`         | `rgba(28,28,30,0.70)`    | 基础深色背景 (bg-[#1C1C1E]/70)             |
| `panel-dark`           | `rgba(255,255,255,0.06)` | 玻璃容器背景                               |
| `content-surface-dark` | `rgba(255,255,255,0.12)` | **新增**: 抽屉内部信息卡片背景，增强对比度 |
| `border-dark`          | `rgba(255,255,255,0.10)` | 容器边框 (glass-border)                    |
| `text-primary`         | `#FFFFFF`                | 主要文字颜色                               |
| `text-secondary`       | `#3C3C4399`              | 次要标签、占位符颜色 (ios-gray-label)      |
| `success`              | `#34C759`                | 在线状态、保存成功                         |
| `danger`               | `#FF3B30`                | 退出登录、错误提示、危险操作               |

### B. 尺寸与圆角 (Sizes & Radius)

- **用户入口卡片**: 宽 260px，高 60px，内边距 12px。
- **头像尺寸**: 40x40 (桌面) / 36x36 (移动)。
- **圆角 (Radius)**:
  - `r-md` (14px): 用于小型卡片。
  - `r-lg` (20px): 用于主要弹窗、抽屉容器。
  - `r-xl` (24px): 苹果标准超大圆角。
- **点击目标**: 移动端最小高度保持 44px。

### C. 动效 (Motion)

- **进入动画**: 160ms `ease-out` (淡入 + 轻微缩放或平移)。
- **退出动画**: 140ms `ease-in`。
- **Hover**: 200ms `linear` 或 `ease-in-out` 的颜色/阴影变化。

## 3. 桌面端排版方案 (Desktop)

### 3.1 左下角入口 (User Card)

- **位置**: 系统导航侧边栏底部。
- **布局**:
  - 左侧: 圆形头像 + 右下角 6px 绿色在线点。
  - 中部: 姓名 (SF Pro, Semi-bold) + 角色标签 (小号胶囊底色)。
  - 右侧: `SettingOutlined` 图标。
- **交互**: 整体可点击，Hover 时背景加深并显现轻微浅蓝色外发光。

### 3.2 弹出菜单 (Popover Menu)

- **触发**: 点击 User Card 弹出，位于卡片上方。
- **内容结构**:
  1.  **顶部卡片**: 重复头像与姓名，含“个人信息”主按钮（Accent 样式）。
  2.  **角色切换区**: 垂直列表，显示用户所有角色。点击即时生效，伴随全局 Toast 提示：“已切换为 [角色名]”。
  3.  **操作区**:
      - “修改密码”：打开独立弹窗。
      - “系统设置”：快速调整主题/字号。
  4.  **底部**: “安全退出”（Danger 色，带二次确认防误触）。

### 3.3 个人信息抽屉 (Profile Drawer)

- **形式**: 右侧推入抽屉，宽度 520px - 560px。
- **Hero 区域**: 104px 高。左侧大头像支持上传点击，中部显示详细工号/账号，底部 banner 提示当前操作角色。
- **栅格布局**:
  - **左列**: 基本资料表单（姓名、手机号、邮箱、个人备注）。
  - **右列**: 我的工作台预览（今日查寝任务数、待处理申诉数、负责楼栋列表迷你卡片）。
- **响应式**: 窗口宽度 < 640px 时自动变为单列瀑布流排版。

## 4. 移动端排版方案 (Mobile)

### 4.1 悬浮入口 (Profile Chip)

- **位置**: 底部 Pill Bar 左上方，避开 Home Indicator 安全区。
- **视觉**: 精简为一个药丸型 Chip (头像 + 姓氏/简称)，高度 44px。

### 4.2 弹出形态 (Action Sheet / Sheet)

- **交互**: 向上推入式半屏 Sheet，顶部中心带灰色拖拽条。
- **层级**:
  - 第一层: 快捷功能（个人信息、切换角色按钮）。
  - 第二层: 统计数据卡片（一排两个）。
  - 第三层: 列表项（修改密码、外观偏好、退出）。

---

## 5. 核心功能逻辑与状态规约

### 5.1 角色切换逻辑

- **即时性**: 选中后立即刷新前端权限 Session，无需重新登录。
- **反馈**: 弹出 `message.success("权限已刷新")`。如果正在抽屉页，内容区组件应根据新权限状态局部 Loading 并重新 fetch 控制权限的字段。

### 5.2 安全退出流程

- **双重确认**: 点击后弹出居中微型对话框，文字描述：“确认退出并清除本地登录状态？”
- **执行**: 清理 `localStorage` 中的 Token、User 信息及缓存配置。

### 5.3 表单保存策略

- **脏检查**: 仅在字段被修改 (Dirty) 时激活“保存修改”按钮。
- **反馈系统**:
  - 保存中: 按钮显示 Loading Spin。
  - 成功: Toast 提示。
  - 错误: 输入框边框变为红色，下方显现微型错误文案。

### 5.4 权限摘要展示

- 在抽屉的“当前角色”下方，用 2-4 个 Chip 展示核心权限（如：`数据导出`、`宿舍管理`、`申诉审批`），并在末尾提供“权限详情”折叠入口。

## 6. 功能映射表 (前端组件 -> 后端接口)

| 页面区块      | UI 元素          | 对应接口/字段                           |
| :------------ | :--------------- | :-------------------------------------- |
| **User Card** | 姓名/头像/角色名 | `myProfile` / `activeRole`              |
| **角色切换**  | 角色列表         | `userRoles` 数组                        |
| **基本资料**  | 编辑表单         | `updateMyContact` (POST)                |
| **统计卡片**  | 任务/申诉数据    | `tasks` / `myInspections` / `myAppeals` |
| **负责区域**  | 楼栋/宿舍列表    | `fetchAssignedDorms`                    |
| **安全中心**  | 修改密码弹窗     | `changePassword` (POST)                 |
| **偏好设置**  | 主题切换/字号    | 前端 `ThemeContext` / `ConfigProvider`  |

---

## 7. 细节打磨 (Polishing)

- **骨架屏 (Skeleton)**: 用户卡片及抽屉在大数据量加载时采用淡灰色 Skeleton。
- **高对比度卡片**: 抽屉内部卡片背景色比容器稍深 (`rgba(255,255,255,0.12)`)，以区分内容层级。
- **键盘支持**: 支持 `Tab` 键循环聚焦，`Esc` 关闭菜单和抽屉。
