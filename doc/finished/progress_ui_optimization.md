### 4. 查寝分数录入页面返回逻辑修复

**问题描述**：移动端下方的"保存并返回"按钮和顶端的返回按钮使用 `navigate(-1)` 导致返回到上一间宿舍的录入页，而不是房间选择页面。

**解决方案**：

- 新增 `getRoomSelectUrl()` 函数生成正确的房间选择页面 URL
- 新增 `handleBackToRoomList()` 函数处理返回逻辑
- 修改顶部返回按钮、无权限返回按钮、以及保存成功后的导航逻辑
- 所有返回操作现在都正确导航到 `/tasks/entry/buildings/:building/floors/:floor/rooms`

**修改文件**：`frontend/src/pages/ResultEntryPage.jsx`
