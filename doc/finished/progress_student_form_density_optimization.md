# 进展文档：学生管理表单信息密度优化

## 任务背景

当前“学生管理-新增学生”弹窗表单字段较多，在标准视口下需要频繁滚动才能看全。为提升用户体验和录入效率，实施“信息密度优化（方案3）”，在不改变字段结构和逻辑的前提下，通过样式和布局进行紧凑排版。

## 当前进展 (2026-01-24)

### 1. 样式系统增强 (index.css)

- **新增 `.apple-form-compact` 统筹类**：
  - **高度压缩**：控件（Input/Select/Picker）高度从 44px 减至 36px，提升首屏容纳率。
  - **边距收窄**：字段间距从 20px 压缩至 12px，Label 与控件间距收窄至 2px。
  - **文字优化**：Label 降至 12px，使用更轻盈的字重，降低视觉干扰。
- **行内 Switch 布局**：修正了 `.form-item-inline-switch` 类，不再破坏 `Form.Item` 的基础结构，改为在 Control 区域内部实现居中对齐，确保 Label 完美对齐。
- **Select 深度对齐**：通过覆盖 `ant-select-single` 的内部搜索框和箭头定位，解决了中线漂移问题。
- **CSS 变量化**：引入 `--control-h` 变量，实现桌面(36px)与移动端(40px)的一键式高度同步。

### 2. 组件逻辑与布局调整 (StudentManagementPage.jsx)

- **容器优化**：
  - **Modal 调优**：宽度增至 880px，支持更宽松的两列排版；body 锁定 70vh 最大高度并内置滚动，强制 Footer 可见。
  - **Drawer 调优**：移动端同步应用紧凑样式。
- **字段呈现**：
  - 将“是否寝室长”由 **Checkbox (独占行)** 改为 **Switch (行内排版)**。
  - 为性别 Select 增加了 `size="middle"` 属性，配合 CSS 显著提升对齐稳定性。
  - **字段分组提示**：通过代码结构和 placeholder（如“如 2024”、“11位手机号”）隐式增强字段引导。

### 3. 多端适配规则

- **桌面端**：双列 Grid (`md:grid-cols-2`)，配合 `compact-grid` (gap-x-4) 优化横向间距。
- **移动端**：强制单列，控件高度稍微放宽至 40px 以保证触控精度，间距调整为 14px。

## 量化达成情况

- **首屏显示率**：在 1366x768 视口下，可见字段数量提升约 40%，滚动条长度显著减少。
- **视觉噪音**：通过减小字体和间距，表单视觉中心更聚焦于输入区域。
