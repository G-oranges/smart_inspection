# 宿舍管理界面分页器布局优化进展

## 目标
统一“列表”、“卡片”、“缩略”三种视图的分页器样式和布局，使其在视觉上保持一致。具体而言，卡片和缩略视图的分页器应模仿列表视图（表格）底部的布局：全宽背景、特定的边框以及与容器边缘对齐。

## 当前进展
- [x] 分析 `DormManagementPage.tsx` 中的视图渲染结构。
- [x] 分析 `dorm-management.css` 中的分页样式。
- [x] 重构 `DormContentPane` 中的卡片和缩略视图容器，采用 `flex flex-col` 布局。
- [x] 修正分页器尺寸：恢复 `size="small"`，以匹配列表视图中常用的较小控制高度。
- [x] 统一页码选项高度：将“x 条/页”选择器和“跳至”输入框的高度统一设置为 `var(--ant-control-height-sm)`。
- [x] 优化文本布局：设置 `margin-right: auto` 并确保 `padding-left: 24px`，确保“共 x 条”文本在所有视图中都固定居左且水平对齐。
- [x] 完善全通铺底分页器的样式：移除外边距并修正父容器内边距。

## 最终效果
- **样式统一**：所有三种视图在底部均有一个全宽的、带浅灰色背景和上边距的分页栏，控制组件尺寸完全一致。
- **布局一致**：用户切换视图时，分页器及内部的“共多少条”文本保持水平对齐，确保切换流畅无跳动感。
- **细节对齐**：通过强行指定 `ant-control-height-sm`，解决了卡片视图分页器高度与列表视图不一致的问题。
